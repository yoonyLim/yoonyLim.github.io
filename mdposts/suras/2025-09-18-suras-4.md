# [SuraS 개발일지 4] 적 협동 공격, 서로 던지기, Charger와 Turret AI

## 1. 개요

### 1.1 사전 배경

SuraS에서 가장 독특하게 구현하고 싶었던 적 패턴은 적들이 서로를 던지는 협동 공격이었다. 일반적인 FPS 적은 각자 독립적으로 행동하지만, 하이퍼 FPS에서는 전투 장면이 더 과장되고 역동적이어야 한다고 생각했다. 그래서 특정 전투 구역에서 적 두 마리가 짝을 이루고, 한 적이 다른 적을 잡아 플레이어 방향으로 던지는 패턴을 만들었다.

이 기능은 단순히 `LaunchCharacter`를 한 번 호출하는 것으로 끝나지 않았다. 다음 요소들이 모두 맞물려야 했다.

1. 협동 공격 트리거 안에 플레이어와 적들이 들어왔는지 감지
2. 사용 가능한 적들을 두 마리씩 페어링
3. 두 적의 Behavior Tree를 잠시 멈추거나 재시작
4. Blackboard에 서로를 `CoopAlly`로 저장
5. 던지는 적과 던져지는 적의 역할 구분
6. Motion Warping으로 애니메이션 방향 보정
7. Animation Notify State로 잡기와 던지기 타이밍 제어
8. 던져진 적이 플레이어와 충돌하면 데미지 적용

## 3. 협동 공격 트리거 박스

협동 공격은 특정 구역에서만 발생하도록 `AEnemyCoopAttackTriggerBox`를 만들었다. 이 Actor는 적 감지용 Box와 플레이어 감지용 Box를 따로 가진다.

```cpp
AEnemyCoopAttackTriggerBox::AEnemyCoopAttackTriggerBox()
{
    EnemiesTriggerBox = CreateDefaultSubobject<UBoxComponent>(FName("Enemies Trigger Box"));
    EnemiesTriggerBox->SetupAttachment(RootComponent);

    PlayerTriggerBox = CreateDefaultSubobject<UBoxComponent>(FName("Player Trigger Box"));
    PlayerTriggerBox->SetupAttachment(RootComponent);
}
```

플레이어가 트리거 안에 들어오면 현재 적 트리거 안에 있는 적들을 모아 협동 공격을 활성화한다.

```cpp
void AEnemyCoopAttackTriggerBox::OnPlayerOverlapBegin(...)
{
    if (Cast<ASuraPawnPlayer>(OtherActor))
    {
        TArray<AActor*> OutActors;
        EnemiesTriggerBox->GetOverlappingActors(OutActors, ASuraCharacterEnemyBase::StaticClass());

        EnemiesForCoopAttack.Empty();

        for (AActor* Actor : OutActors)
        {
            if (ASuraCharacterEnemyBase* EnemyActor = Cast<ASuraCharacterEnemyBase>(Actor))
                EnemiesForCoopAttack.AddUnique(EnemyActor);
        }

        bIsPlayerInsideTrigger = true;
        ActivateCoopAttack();
    }
}
```

이렇게 한 이유는 플레이어가 구역에 들어오기 전부터 적들이 서로 던지는 것이 아니라, 플레이어가 실제 전투 구역에 진입했을 때 이벤트성 패턴이 발생하도록 하기 위해서였다.

## 4. 적 페어링과 상태 전환

`ActivateCoopAttack`은 협동 공격 가능한 적들을 모아 두 마리씩 짝지은 뒤, 한쪽을 던지는 적, 다른 한쪽을 던져지는 적으로 설정한다.

```cpp
if (AvailableEnemies.Num() >= 2)
{
    while (AvailableEnemies.Num() >= 2)
    {
        ASuraCharacterEnemyBase* EnemyA = AvailableEnemies[0];
        ASuraCharacterEnemyBase* EnemyB = AvailableEnemies[1];

        EnemyA->GetAIController()->GetBrainComponent()->RestartLogic();
        EnemyB->GetAIController()->GetBrainComponent()->RestartLogic();

        if (EnemyA != EnemyB)
        {
            EnemyA->GetAIController()->SetStateToCoopAttack(EnemyB, true);
            EnemyB->GetAIController()->SetStateToCoopAttack(EnemyA, false);
        }

        AvailableEnemies.RemoveAt(1);
        AvailableEnemies.RemoveAt(0);
    }
}
```

`SetStateToCoopAttack`은 AI Controller에서 Blackboard에 협동 공격에 필요한 정보를 기록한다.

```cpp
void AEnemyBaseAIController::SetStateToCoopAttack(AActor* Ally, bool bIsPitcher)
{
    UpdateCurrentState(EEnemyStates::CoopAttacking);
    GetBlackboardComponent()->SetValueAsObject("CoopAlly", Ally);
    GetBlackboardComponent()->SetValueAsBool("IsCoopThrower", bIsPitcher);
}
```

이 구조 덕분에 Behavior Tree 안에서는 `IsCoopThrower` 값을 보고 던지는 적과 던져지는 적의 분기를 나눌 수 있었다.

## 5. Behavior Tree Task: Coop Attack

협동 공격의 실제 실행은 `BTT_CoopAttack`에서 처리했다. 이 Task는 현재 적, 협동 대상 적, 플레이어를 캐싱하고 공격 몽타주를 실행한다.

```cpp
if (ASuraCharacterEnemyBase* const Enemy = Cast<ASuraCharacterEnemyBase>(OwnerComp.GetAIOwner()->GetCharacter()))
{
    CachedEnemy = Enemy;
    CachedEnemyAlly = Cast<ASuraCharacterEnemyBase>(
        Enemy->GetAIController()->GetBlackboardComponent()->GetValueAsObject("CoopAlly")
    );

    OnAttackMontageEnded.BindUObject(this, &UBTT_CoopAttack::OnAttackEnded, &OwnerComp);

    UAnimInstance* const EnemyAnimInstance = Enemy->GetMesh()->GetAnimInstance();
    UAnimMontage* CoopAttackMontage = Enemy->GetCoopAttackMontage();

    EnemyAnimInstance->Montage_Play(CoopAttackMontage);
    EnemyAnimInstance->Montage_SetEndDelegate(OnAttackMontageEnded, CoopAttackMontage);
}
```

Tick에서는 Motion Warping Target을 계속 갱신한다. 던지는 적은 먼저 협동 대상 적을 향해야 하고, 이후 플레이어 방향으로 몸을 돌려야 한다.

```cpp
FRotator FaceEnemyAllyRotation =
    (EnemyAlly->GetActorLocation() - Enemy->GetActorLocation()).GetSafeNormal2D().Rotation();

Enemy->GetMotionWarpingComponent()->AddOrUpdateWarpTargetFromLocationAndRotation(
    "EnemyAllyToGrab",
    Enemy->GetActorLocation(),
    FaceEnemyAllyRotation
);

FRotator FacePlayerRotation =
    (Player->GetActorLocation() - Enemy->GetActorLocation()).GetSafeNormal2D().Rotation()
    + FRotator(0.0f, 110.0f, 0.0f);

Enemy->GetMotionWarpingComponent()->AddOrUpdateWarpTargetFromLocationAndRotation(
    "AttackTargetToFace",
    Enemy->GetActorLocation(),
    FacePlayerRotation
);
```

Motion Warping을 사용하지 않으면 몽타주가 항상 같은 방향으로 재생되어 실제 적과 플레이어 위치에 맞지 않는다. 협동 공격처럼 두 Actor의 상대 위치가 중요한 애니메이션에서는 Motion Warping이 거의 필수였다.

## 6. Animation Notify State: 잡기와 던지기

협동 공격에서 가장 중요한 순간은 던지는 적이 다른 적을 실제로 잡는 시점과 놓는 시점이다. 이를 위해 `ANS_GrabCoopAttackAlly`를 만들었다.

Notify가 시작될 때는 협동 대상 적을 던지는 적의 CapsuleComponent에 Attach한다. 동시에 두 적 사이의 충돌을 잠시 무시해 서로 밀어내지 않게 했다.

```cpp
OwnerEnemy->GetMesh()->IgnoreActorWhenMoving(AllyEnemy, true);
OwnerEnemy->GetCapsuleComponent()->IgnoreActorWhenMoving(AllyEnemy, true);

FAttachmentTransformRules AttachmentRules(EAttachmentRule::SnapToTarget, true);
AttachmentRules.RotationRule = EAttachmentRule::KeepWorld;
AllyEnemy->AttachToComponent(
    OwnerEnemy->GetCapsuleComponent(),
    AttachmentRules,
    FName(TEXT("RightHand"))
);
```

Notify가 끝날 때는 적을 Detach하고 플레이어 위치를 향해 Launch한다.

```cpp
FDetachmentTransformRules DetachmentRules(EDetachmentRule::KeepWorld, true);
AllyEnemy->DetachFromActor(DetachmentRules);

FVector AttackTargetLocation = Player->GetActorLocation();
FVector FinalDestination = FVector(AttackTargetLocation.X, AttackTargetLocation.Y, AttackTargetLocation.Z + 250.f);
FVector LaunchVelocity = FinalDestination - AllyEnemy->GetActorLocation();

AllyEnemy->LaunchCharacter(LaunchVelocity * 3.f, true, true);
```

이 방식은 단순하지만 효과적이었다. 애니메이션의 손 위치에 실제 Actor를 붙였다가, Notify 종료 시점에 플레이어 방향으로 던지기 때문에 애니메이션과 게임플레이가 자연스럽게 이어진다.

## 7. 던져진 적의 데미지 처리

던져진 적은 `BTT_GetYeeted` Task에서 처리된다. Task가 시작되면 Falling Montage를 재생하고 Capsule Hit 이벤트를 구독한다.

```cpp
CachedEnemy = Cast<ASuraCharacterEnemyBase>(OwnerComp.GetAIOwner()->GetCharacter());
bIsDoneGettingYeeted = false;

if (ASuraCharacterEnemyBase* Enemy = CachedEnemy.Get())
{
    Enemy->GetCapsuleComponent()->OnComponentHit.AddDynamic(this, &UBTT_GetYeeted::OnHit);

    UAnimInstance* const EnemyAnimInstance = Enemy->GetMesh()->GetAnimInstance();
    UAnimMontage* FallingMontage = Enemy->GetFallingMontage();

    EnemyAnimInstance->Montage_Play(FallingMontage);
}
```

플레이어와 충돌하면 Charge 타입 데미지를 주고, 플레이어가 적의 어느 쪽에 있는지 계산하여 밀려나는 방향도 함께 전달했다.

```cpp
FVector DirectionToOther = (OtherActor->GetActorLocation() - Enemy->GetActorLocation()).GetSafeNormal2D();
FVector ChargerRightVector = Enemy->GetActorRightVector().GetSafeNormal2D();

float SideSign = FMath::Sign(FVector::DotProduct(ChargerRightVector, DirectionToOther));
FVector PerpendicularDirection = ChargerRightVector * SideSign;

FDamageData DamageData;
DamageData.DamageAmount = Enemy->GetAttackDamageAmount();
DamageData.DamageType = EDamageType::Charge;
DamageData.ImpulseDirection = PerpendicularDirection;
DamageData.ImpulseMagnitude = 1000.f;

Player->TakeDamage(DamageData, Enemy);
```

이 부분은 단순히 체력을 깎는 것보다 중요했다. 하이퍼 FPS에서 강한 공격은 플레이어의 위치와 움직임에도 영향을 줘야 하기 때문이다.

## 8. Charger AI

Charger는 플레이어에게 돌진하는 적이다. `BTT_ChargeAttack`은 먼저 준비 애니메이션을 재생하고, 이후 돌진 상태로 들어간다.

```cpp
UAnimMontage* AttackReadyAnimation = CachedWeakCharger->GetChargeReadyAnimation();
float AttackReadyAnimDuration = CachedWeakCharger->PlayAnimMontage(AttackReadyAnimation);

GetWorld()->GetTimerManager().SetTimer(
    AnimCompleteHandle,
    [WeakThis]()
    {
        if (auto Task = WeakThis.Get())
        {
            if (auto Charger = Task->CachedWeakCharger.Get())
                Task->OnAttackReadyEnded(Charger);
        }
    },
    AttackReadyAnimDuration,
    false
);
```

돌진이 시작되면 이동 속도와 가속도를 높이고 AI Focus를 제거하여 정면으로만 달려가게 했다.

```cpp
bIsAttacking = true;

OriginalMaxWalkSpeed = Charger->GetCharacterMovement()->MaxWalkSpeed;
Charger->GetCharacterMovement()->MaxWalkSpeed = ChargeMaxWalkSpeed;
Charger->GetCharacterMovement()->MaxAcceleration = ChargeMaxWalkSpeed;
Charger->GetCharacterMovement()->bRequestedMoveUseAcceleration = false;

Charger->GetAIController()->ClearFocus(EAIFocusPriority::Gameplay);
Charger->ActivateDashEffect();
```

벽에 부딪히면 Stun Animation을 재생하고, 플레이어에게 부딪히면 Charge Damage를 적용한다. Charger는 단순히 빠른 적이 아니라 플레이어의 회피 타이밍을 강제하는 역할을 했다.

## 9. Turret AI

Turret 적은 이동보다 시야와 사격 압박이 중요한 적이다. 그래서 `AEnemyBaseAIController::OnTargetSighted`에서도 Turret은 별도로 처리했다.

```cpp
if (Cast<ASuraCharacterEnemyTurret>(CachedPossessedPawn.Get()))
{
    if (ASuraPawnPlayer* const Player = Cast<ASuraPawnPlayer>(SeenTarget))
    {
        GetBlackboardComponent()->SetValueAsObject("AttackTarget", Player);
        UpdateCurrentState(EEnemyStates::Attacking);
    }
}
```

일반 적은 플레이어를 보면 Chase/Pursue로 들어가지만, Turret은 이동할 필요가 없기 때문에 바로 Attacking 상태로 전환한다. 같은 AI Controller를 사용하면서도 적 타입별로 다른 상태 전환을 적용한 사례이다.

## 10. 후기

협동 공격은 구현 중 버그가 많이 생겼던 기능이다. 적 둘의 상태가 동시에 바뀌어야 하고, BrainComponent를 멈췄다가 재시작해야 하며, 몽타주 종료 시 Blackboard 값을 정리해야 했다. 한쪽 적이 죽거나 트리거 밖으로 나가는 경우도 처리해야 했다.

하지만 완성 후에는 SuraS의 적 AI 중 가장 프로젝트 성격이 잘 드러나는 기능이 되었다. 적이 단순히 플레이어를 따라오는 것이 아니라, 서로 상호작용하며 공간을 압박하는 패턴을 만들 수 있었기 때문이다.

개인적으로 이 작업은 "AI는 생각하는 캐릭터"라기보다 "전투 장면을 연출하는 시스템"이라는 점을 가장 크게 배운 부분이었다.
